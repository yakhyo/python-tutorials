# Sinov maydonçasi

Kiçik ğoyalarni şu yerda sinab köring. Kodni işga tuşiriş uçun **Ctrl + Enter** (Mac: **⌘ + Enter**) ni bosing. **Töxtatiş** Python seansini qayta işga tuşiradi.

<ClientOnly><PythonPlayground /></ClientOnly>

## Bilib qöyiş foydali

- Har bir işga tuşiriş toza özgaruvçilar bilan boşlanadi.
- `input()` uçun javoblarni oldindan **input() uçun qiymatlar** bölimiga, har birini alohida qatorga yozing.
- Siz yaratgan fayllar faqat brauzerda mavjud va seans qayta boşlanganda yöqoladi.
- Faqat standart kutubxona mavjud, juda uzoq davom etadigan kod 15 soniyadan keyin töxtatiladi.
- Daftarlar va fayllar bilan uzoqroq tajribalar uçun [Python laboratoriyasi](/uz/laboratoriya)dan foydalaning.
- Maşhur maʼlumot paketlari (numpy, pandas, matplotlib) birinçi marta import qilinganda avtomatik yuklanadi, `plt.show()` esa grafiklarni natija ostida körsatadi.
