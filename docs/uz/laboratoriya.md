# Python laboratoriyasi

Python laboratoriyasi - butunlay brauzeringizda işlaydigan töliq **daftar muhiti** (notebook environment). U [JupyterLite](https://jupyterlite.readthedocs.io/) va Pyodide asosidagi Python yadrosi (kernel) bilan işlaydi, şuning uçun heç narsa örnatiş şart emas.

## Içida nimalar bor

- **00-start-here.ipynb**: daftarlar bilan işlaşga qisqa kiriş.
- **Har bir modul uçun bitta maşq daftari**: darslardagi barça maşqlar özbek va ingliz tilida, har birining ostida javobingiz uçun böş kod katakçasi (cell). Yeçimlar darslarda qoladi: avval özingiz urinib köring, keyin tekşiring.
- Fayl brauzeri: öz daftarlaringiz, matn va CSV fayllaringizni yaratiş uçun.

## Sinov maydonçasimi yoki laboratoriya?

| | Sinov maydonçasi va dars muharrirlari | Python laboratoriyasi |

## Daftarlardan foydalaniş

1. Çapdagi fayl brauzeridan daftarni oçing.
2. Kod katakçasini bosing, kodingizni yozing va işga tuşiriş uçun **Shift + Enter** ni bosing.
3. Özgaruvçilar keyingi katakçalarda ham mavjud bölib qoladi, şuning uçun katakçalarni yuqoridan **tartib bilan** işga tuşiring.
4. Çalkaşlik bölsa, **Kernel → Restart Kernel and Clear Outputs** ni tanlang va yana yuqoridan işga tuşiring.

::: warning Işingizni saqlang
Daftarlar **faqat şu brauzerda** saqlanadi. Sayt maʼlumotlarini tozalaş yoki boşqa brauzerga ötiş ularni öçirib yuboradi. Muhim daftarlarni kompyuteringizga saqlaş uçun **File → Download** dan foydalaning.
:::

## Çeklovlar

- Birinçi işga tuşirişda Python yuklab olinadi, bu biroz vaqt olişi mumkin.
- Pyodide qöllab-quvvatlaydigan paketlar (numpy, pandas, matplotlib kabi) işlaydi. Boşqa köp paketlar esa işlamaydi.
- Python kodidan tarmoqqa ulaniş brauzer xavfsizlik qoidalari bilan çeklangan.
- Katta loyihalar uçun Pythonni kompyuteringizga örnating (*Pythonni örnatiş* darsini qarang).
