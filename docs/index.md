# Learn Python

<div class="course-intro">Start from zero. Write code, run it right on the page, and build real skills one lesson at a time.</div>

This course is for people who are new to programming, or new to Python. Every lesson explains one idea with short examples, shows the mistakes beginners usually make, and ends with exercises you can check yourself. You don't need to install anything to begin: examples run in your browser.

**[Start learning →](/lessons/what-is-python)** · [Open the playground](/playground) · [Özbekça versiya](/uz/)


## Learning path

| Part | Modules | You'll be able to |
| --- | --- | --- |
| **1 · Foundations** | Getting started · Values and variables · Decisions · Loops · Collections · Functions | Write small programs that make decisions, repeat work, and organize data |
| **2 · Writing real programs** | Modules and the standard library · Errors and files · Classes and objects · Object-oriented design · Testing and debugging · Going further · Working with data (optional) | Read and write files, handle errors, design classes, test your code, and analyze data |

## Practice built in

- **Run every example.** Each code block has a **Run** button that opens it in an editor right on the page.
- **Check your exercises.** Under each exercise, **Solve in the browser** opens an editor with a **Check** button that compares your output with the expected output.
- **Build projects.** Seven guided projects: a number guessing game, a quiz game, an expense tracker, a library management system, a text analyzer, a sales data report, and a log pipeline.
- **Test yourself.** Every module ends with a short **checkpoint quiz**.
- **Experiment freely.** Use the [Playground](/playground) for quick code, or the [Python Lab](/lab) for notebooks with practice exercises for every module.

## How to use this course

1. **Go in order.** Each lesson builds on the ones before it.
2. **Predict, then run.** Before running an example, guess the output.
3. **Break things on purpose.** Change a value or delete a line and see what happens.
4. **Try exercises before opening solutions.** Stars show difficulty: <Difficulty level="1" /> easy, <Difficulty level="2" /> medium, <Difficulty level="3" /> hard.
5. **Take the checkpoint quiz** at the end of each module. Your best score is saved in your browser, with no account needed.

## What you need

A modern browser and some practice time. The first run of a code example downloads Python into your browser, so it needs an internet connection. Examples target **Python 3.14**.
