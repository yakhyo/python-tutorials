# Python Tutorials

A Python course in English and Uzbek that runs in the browser, with nothing to install. For programming videos in Uzbek, see the [codeuz](https://youtube.com/codeuz) YouTube channel.

**[Özbekça](https://codeuz-edu.github.io/python-tutorials/uz/)** · **[English](https://codeuz-edu.github.io/python-tutorials/en/)**

It has a 12-module Python course and a follow-on track, Working with Data. The next step after it is [Advanced Python](https://codeuz-edu.github.io/python-advanced/).

## Run locally

Requires Node.js 22+.

```sh
npm ci
npm run dev
```
